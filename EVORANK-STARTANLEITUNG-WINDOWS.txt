EVORANK 10.9 – WINDOWS STARTANLEITUNG

1. Die ZIP-Datei vollständig entpacken.
2. EVORANK.exe doppelklicken.
3. Falls Windows nachfragt, das lokale PowerShell-Fenster zulassen.
4. EvoRank öffnet sich automatisch im Standardbrowser.
5. Das PowerShell-Fenster während der Nutzung geöffnet lassen.

Alternativ kann EVORANK-STARTEN.bat verwendet werden.

Wichtig:
- Node.js wird nicht benötigt.
- Python wird nicht benötigt.
- Es wird nichts installiert.
- Der lokale Server ist nur über 127.0.0.1 auf diesem Computer erreichbar.
- Trainingsdaten bleiben im Browserprofil des Computers gespeichert.
- Die 500 Dehn- und Mobilitätsübungen funktionieren vollständig lokal.
- Gemeinsame Top-10-Bestenlisten benötigen die Netlify-/Supabase-Version.
- Die dauerhafte Garmin-Verbindung benötigt die Netlify-/Supabase-Version;
  in der lokalen Windows-Ausgabe bleibt der Garmin-Dateiimport verfügbar.
