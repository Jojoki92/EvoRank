EvoRank X5.7
==============

START
1. Öffne index.html über einen HTTPS-Webserver oder das Windows-Startprogramm.
2. Melde dich an oder verwende die App lokal.
3. Unter Profil → Sicherheit, Cloud & Support verwaltest du Cloud, Bestenlisten, Garmin,
   Diagnose, Backup und Datenprüfung.

WICHTIG
- Ohne ausdrückliche Freigabe werden keine neuen Daten an Cloud, Bestenliste
  oder Garmin übertragen.
- Erstelle regelmäßig ein JSON-Backup.
- 500 Mobilitätsübungen sind enthalten; „Geprüfte Basis“ zeigt 50 sanfte
  Standardvarianten. Sie ersetzen keine medizinische Beratung.
- Garmin benötigt Developer-Freigabe und Servervariablen.
- Widget und Dynamic Island benötigen die native Xcode-App.

EINRICHTUNG
Die aktuelle Windows-Anleitung liegt im übergeordneten Windows-Paket.
Das kompatible Datenbank-Setup findest du dort unter BESTENLISTEN-EINRICHTEN.
Das Netlify-Paket enthält die bestehende Hosting- und Funktionskonfiguration.
Veröffentlichen erfolgt getrennt; eine lokale Kopie aktualisiert keine Website.
