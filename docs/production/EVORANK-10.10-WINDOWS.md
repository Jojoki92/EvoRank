# EVORANK 10.10 – Windows

Die Windows-Ausgabe heißt normal `EVORANK-10.10-WINDOWS.zip`.

- **Empfohlen:** `EVORANK.exe` startet einen lokalen Server und öffnet die App.
- **Alternative:** `EVORANK-STARTEN.bat` verwendet PowerShell.
- **Node.js-Fallback:** `EVORANK-START-MIT-NODE.bat` nutzt Node.js, wenn es installiert ist.

Die App bindet nur an `127.0.0.1`; sie wird dadurch nicht im Heimnetz freigegeben.
Cloud, Garmin und E-Mail benötigen Internet und die jeweilige Serverkonfiguration.
Die lokale Windows-Ausgabe allein enthält keine geheimen Serverzugänge.
